# Меню HahGps в стиле основного плагина hahtojer

Меню GPS специально сделаны неотличимыми от меню основного плагина **hahtojer**:
игрок не должен замечать, что это два разных плагина. Всё оформление собрано в
одном классе — `ru.hahgps.gui.GuiTheme`.

## Палитра

10 тонов от ночного синего к светло-бирюзовому (`GuiTheme.TONES`):

| № | HEX | Название |
|---|---|---|
| 0 | `#08122b` | ночной |
| 1 | `#0e2450` | глубокий |
| 2 | `#14397e` | тёмно-синий |
| 3 | `#1d51a8` | синий |
| 4 | `#2464c8` | синий ярче |
| 5 | `#3f86ff` | ярко-синий |
| 6 | `#66aaff` | голубой |
| 7 | `#8fc6ff` | светло-голубой |
| 8 | `#4fd1e0` | бирюзовый |
| 9 | `#8fe9f5` | светло-бирюзовый |

Нейтральные: `§f` — значения, `§7` — пояснения, `§8` — разделители, `§c` — только
ошибки. Запрещены чужие цвета: `§a`, `§e`, `§6`, `§d`, `§2`, `§4`, `§5`.

## Помощники `GuiTheme`

| Метод | Что делает |
|---|---|
| `gradientTitle(text)` | заголовок меню: градиент `#0e2450 → #2464c8 → #8fe9f5`, жирный |
| `gradient(text)` / `gradient(text, from, to)` | текст в фирменном градиенте |
| `toned(i, text)` | текст в тоне палитры по индексу |
| `named(mat, name, lore)` | предмет с именем и описанием (понимает и `§`-коды, и MiniMessage) |
| `glow(item)` | свечение активных кнопок |
| `filler()` / `fill(inv)` | синие панели фона (`BLUE_STAINED_GLASS_PANE`) |
| `navBack` / `navForward` / `navInfo` / `navClose` | элементы навигации |
| `brand(version)` | бренд-предмет `HahGPS` в углу (не кликается и не выдаётся) |
| `click` / `page` / `deny` | звуки клика, страницы, отказа |

## Холдер и клики (важно)

Три правила, без которых меню «мертвеет» — из-за них в 1.0.0 кнопки не работали,
а предметы забирались в инвентарь:

1. **Холдер инвентаря — сам экран.** `GuiScreen implements InventoryHolder`, и
   инвентарь создаётся как `Bukkit.createInventory(this, ...)`. С `null`-холдером
   Paper не даёт отличить наше меню от чужого.
2. **Регистрация — после открытия.** `GuiScreen.open()` сначала зовёт
   `player.openInventory(inventory)` (это закрывает прежний контейнер — свой
   инвентарь игрока или предыдущее меню), и только потом
   `GuiManager.register(player, this)`. Если зарегистрировать раньше, то
   `InventoryCloseEvent` от закрытия старого контейнера снимет свежую регистрацию —
   клики перестанут отменяться.
3. **`onClose` проверяет холдер.** `GuiListener.onClose` снимает с регистрации,
   только если закрывается именно наш `GuiScreen`; закрытие своего инвентаря
   регистрацию не трогает.

Дополнительно `GuiListener.onClick` отменяет клик и закрывает меню, если холдер —
наш экран, но в `GuiManager` его нет (остаток от прежней копии плагина после
перезагрузки): так из «мёртвого» меню нельзя забрать предметы.

Все клики отменяются, включая `InventoryDragEvent`; клики по нижнему инвентарю
игрока игнорируются.

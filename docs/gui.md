# Меню HahGps в стиле основного плагина hahtojer

Меню GPS специально сделаны неотличимыми от меню основного плагина **hahtojer**:
игрок не должен замечать, что это два разных плагина. Всё оформление собрано в
одном классе — `ru.hahgps.gui.GuiTheme`.

## Палитра

`GuiTheme.PALETTE` — **одна синяя линейка из 10 тонов** (`GuiTheme.TONES`).
Других оттенков нет: ни зелёных, ни красных, ни золотых, ни оранжевых,
ни фиолетовых, ни розовых. Разделы плагина различаются не цветом, а тоном
синего и начертанием (✔ / ✖ / →, жирный, курсив).

| Базовые тона (`TONES` = `PALETTE`) | HEX |
|---|---|
| ночной | `#08122b` |
| глубокий | `#0e2450` |
| тёмно-синий | `#14397e` |
| синий | `#1d51a8` |
| синий ярче | `#2464c8` |
| ярко-синий | `#3f86ff` |
| голубой | `#66aaff` |
| светло-голубой | `#8fc6ff` |
| бирюзовый | `#4fd1e0` |
| светло-бирюзовый | `#8fe9f5` |

Нейтральные: `<white>` — значения, `<gray>` — подписи и пояснения,
`<dark_gray>` — разделители (`|`, скобки, точки). Именованные цвета
(`<red>`, `<gold>` и прочие) в сообщениях запрещены — только хексы из
палитры; `GuiTheme.legacyToMini` переводит `§`-коды в тона палитры,
`MessagesManager.remapPalette` чинит старые файлы сообщений. Схема палитры —
`palette-version: 6`, старые файлы сообщений заменяются эталоном (`.bak`).

### Роли цветов в сообщениях

| Роль | Цвет |
|---|---|
| Успех `✔` | `#8fe9f5` (самый светлый тон) |

| Значения, имена точек | `<white>` + `<bold>` |
| Разделители в списках | `<dark_gray>` |
| Префикс | `<gray>[</gray><bold><gradient:#2464c8:#8fe9f5>GPS</gradient></bold><gray>]</gray>` |
| Заголовок меню | градиент `#0e2450 → #2464c8 → #8fe9f5`, жирный |

### Шаблоны строк

Все сообщения одного вида собраны по шаблонам (проверяется тестом
`lineTemplatesAreUniform`):

| Шаблон | Вид |
|---|---|
| Успех | `<#8fe9f5>✔</#8fe9f5> <gray>Точка</gray> <white><bold>{name}</bold></white> <dark_gray>создана.</dark_gray>` |

## Шрифты и размеры (ванильные, ресурспак не нужен)

Обычный текст — стандартный шрифт Minecraft, без переключений.
«Разные шрифты» — это **декорации**: `<bold>` (жирный), `<italic>`
(курсив), `<underlined>`, `<strikethrough>`.

| Шрифт | Тег | Где применяется |
|---|---|---|
| Стандартный | без тега | весь текст: заголовки, значения, подписи, числа |
| Мини (другой размер) | `<font:minecraft:uniform>` | **только время и версии**: `{date}` в карточке точки, `{version}` и `{date}` в объявлениях об обновлении, версия в бренд-предмете |

Правила (проверяются тестами `MessagesPaletteTest`):

- размер шрифта меняется только для `{date}`, `{time}`, `{version}`
  (`sizeAccentOnlyForTimeAndVersions`);
- числа и координаты в мини-шрифте запрещены (`numbersNeverUseTheTinyFont`);
- ключ шрифта только `minecraft:uniform`, все `</font>` закрыты
  (`fontTagsAreClosedAndUseVanillaKeys`);
- руны `minecraft:alt` убраны полностью — они не рисуют цифры и кириллицу;
- `distance-format` / `distance-format-km` — **без разметки**: они уходят
  в BossBar обычным текстом (BossBar в Bukkit не умеет MiniMessage).

## Текст не вылезает за границы

Ни один текст не должен вылезать за окно меню или подсказку предмета:

| Что | Предел | Кто режет |
|---|---|---|
| Заголовок окна | 28 симв. | `gradientTitle` → `clipPlain` |
| Имя предмета | 30 симв. | `GuiTheme.named` → `clipMini` |
| Строка подсказки (lore) | 40 симв. | `GuiTheme.named` → `clipMini` |
| Имена из данных (точки, категории, запросы) | 30 симв. | `MessagesManager.format` |

`clipMini` режет по видимым символам, не считая теги, и закрывает все
открытые теги в конце — обрезанная строка остаётся валидной разметкой.
Пределы проверяет тест `guiTextsFitTheirBoxes`.


## Помощники `GuiTheme`

| Метод | Что делает |
|---|---|
| `gradientTitle(text)` | заголовок меню: градиент `#0e2450 → #2464c8 → #8fe9f5`, жирный, обрезан до 28 симв. |
| `gradient(text)` / `gradient(text, from, to)` | текст в фирменном градиенте |
| `toned(i, text)` / `toneColor(i)` / `toneTag(i)` | тон базовой линейки по индексу |
| `clipPlain(text, max)` / `clipMini(mini, max)` | обрезка под границы окна/подсказки (с закрытием тегов) |
| `micro(mini)` | мини-шрифт — только время и версии |
| `named(mat, name, lore)` | предмет с именем и описанием (понимает и `§`-коды, и MiniMessage) |
| `glow(item)` | свечение активных кнопок |
| `filler()` / `fill(inv)` | синие панели фона (`BLUE_STAINED_GLASS_PANE`) |
| `navBack` / `navForward` / `navClose` / `navInfo` | навигационные кнопки (стрелка/барьер + градиент) |
| `brand(lore)` | бренд-предмет `HahGPS` в углу (не кликается и не выдаётся) |
| `safe(mini)` | разбор MiniMessage с защитой: плохая разметка не роняет команду |
| `plainOf(mini)` | текст без разметки (для кнопок с градиентом) |
| `click` / `page` / `deny` | звуки клика, страницы, отказа |

Помощники экрана `GuiScreen`: `comp(key, …)` — компонент из `messages_*.yml`,
`lore(key, …)` — пояснение под кнопкой, `getMsg(key)` — голая строка для
плейсхолдеров, `putBrand()` — бренд в свободный угол.

Пагинация обязательна с клампом (`Math.max` / `Math.min`), клик возможен только
по реально отображаемым слотам (`slot < показано`), иначе из-под панелей открываются
невидимые элементы.

## Холдер и клики (важно)

Три правила, без которых меню «мертвеет» — из-за них в 1.0.0 кнопки не работали,
а предметы забирались в инвентарь:

1. **Холдер инвентаря — сам экран.** `GuiScreen implements InventoryHolder`, и
   инвентарь создаётся как `Bukkit.createInventory(this, ...)`. С `null`-холдером
   Paper не даёт отличить наше меню от чужого.
2. **Регистрация — после открытия.** `GuiScreen.open()` сначала зовёт
   `player.openInventory(inventory)` (это закрывает прежний контейнер — свой
   инвентарь игрока или предыдущее меню), и только потом
   `GuiManager.register(player, this)`. Если зарегистрировать раньше, то
   `InventoryCloseEvent` от закрытия старого контейнера снимет свежую регистрацию —
   клики перестанут отменяться.
3. **`onClose` проверяет холдер.** `GuiListener.onClose` снимает с регистрации,
   только если закрывается именно наш `GuiScreen`; закрытие своего инвентаря
   регистрацию не трогает.

Дополнительно `GuiListener.onClick` отменяет клик и закрывает меню, если холдер —
наш экран, но в `GuiManager` его нет (остаток от прежней копии плагина после
перезагрузки): так из «мёртвого» меню нельзя забрать предметы.

Все клики отменяются, включая `InventoryDragEvent`; клики по нижнему инвентарю
игрока отменяются без реакции.

## Асинхронное построение

Списки точек и категорий грузятся из хранилища асинхронно и возвращаются на главный
поток через `DataService.runSync(...)`. Перед отрисовкой экран проверяет
`GuiManager.getInstance().get(player) == this` — если игрок уже закрыл меню,
результат никуда не пишется (нет гонок и «зомби»-инвентарей).

## Меню поиска (1.2.0)

- Процент совпадения **не печатается** в списке: он в подсказке при наведении
  вместе с полным названием, координатами и числом игроков, которые искали это
  место. Проценты в чате (`/gps search`) тоже убраны — там название, координаты
  и число искавших.
- Кнопка «Мест в поиске» (слот 24 без результатов, 49 с результатами) меняет
  лимит 1–25: ЛКМ +1, ПКМ −1, Shift — по 5. Настройка своя у каждого игрока,
  по умолчанию — `search.max-results` из `config.yml` (клампится к 1–25).
- `/gps search -n 3 <запрос>` задаёт лимит на один запрос. Число в конце запроса
  лимитом **не считается** — «Хайсовская 10» это адрес, а не «10 результатов».

## Меню карты (1.3.1)

Клиент Minecraft рисует содержимое карты только когда она в руке или в рамке —
в слоте меню видна лишь иконка. Поэтому меню карты — это пульт:

| Слот | Кнопка | Что делает |
|---|---|---|
| 4 | «О карте» | масштаб, текущий центр, включено ли следование |
| 10/12/19/21 | стрелки | сдвиг на четверть полотна (карта при этом закрепляется) |
| 11/15 | «Приблизить» / «Отдалить» | масштаб карты |
| 13 | «Центр на мне» | центр на игроке и снова следование за ним |
| 16 | «Следовать за мной» | переключатель следования (подсвечен, когда включён) |
| 24 | «Открыть карту» | показать карту в руке |

В руке карта **сама едет за игроком** (`map.follow-player`), поэтому смотреть
по сторонам можно спокойно. Панорама — только **Shift+мышь**: полотно
сдвигается, как будто его тянут за курсором, и карта закрепляется в этой
точке. ПКМ по воздуху возвращает центр на игрока и снова включает следование,
Shift+ПКМ открывает это меню. На полотне у верхнего края нарисована стрелка
«север». Название мира в меню и на карте не выводится.

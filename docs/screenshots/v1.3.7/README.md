# Скриншоты проверки v1.3.7

Сняты с **живого сервера** Paper 1.21.11 (`HahGps 1.3.7`, `HahGps enabled. Storage: sqlite`):
бот (mineflayer, MC 1.21.11) открывал меню плагина и снимал содержимое окон ровно в том виде,
в каком его отдаёт сервер — заголовок окна, слоты, названия и подсказки (lore) предметов.

Рендер в PNG — `render.py` из тестового стенда (серверного клиента на машине нет),
поэтому предметы показаны цветными плашками с первой буквой названия, а точный текст
(название, подсказки, код трекера) выведен списком под сеткой слотов.

| Файл | Что показывает |
|---|---|
| `01-main-menu.png` | Главное меню: кнопки, названия, подсказки |
| `02-points-list.png` | «Мои точки»: список, **бренд HahGPS в слоте 44**, **кнопка «Назад» в слоте 45**, **«Страница 1/1» в слоте 49** — три исправленных бага сразу |
| `03-poi-actions.png` | Карточка точки: инфо, маршрут, оценка, удаление |
| `05-back-to-main.png` | Возврат из списка в главное меню (слот 45) |
| `06-categories.png` | Категории |
| `08-back-to-categories.png` | Возврат из списка категории обратно в «Категории» (раньше уводило в общее меню) |
| `10-search-results.png` | Результаты поиска |
| `11-itrak-menu.png` | Меню iTrak |

На `02-points-list.png` в инвентаре бота видны выданные предметы iTrak: трекеры со **старыми 8-значными**
кодами (`TRK-03000001-2F1E` — записи из базы прежней сборки) и **новыми 7-значными** (`TRK-5000001-D8FC`,
`TRK-5000002-D825`), водонепроницаемый трекер «Лодка», локатор ×3 (радиус 20) и терминал ×3.
Это и есть проверка совместимости: `baseOf` теперь разбирает номер любой длины, поэтому старые коды
не выдаются повторно после смены формата.
